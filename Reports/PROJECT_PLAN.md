# Project plan

## Delivered in this repository
- Streamlit dashboard with overview, pricing/category, customer voice and product explorer tabs.
- CSV upload so the public app can run without committing the private/source dataset.
- Python cleaning, profiling and keyword sentiment scripts.
- PostgreSQL schema, analysis queries and views.
- Power BI data model and DAX guidance.
- Unit tests and GitHub Actions test workflow.

## Deployment
Deploy on Streamlit Community Cloud:
1. Sign in to Streamlit Community Cloud using GitHub.
2. Choose **New app** and select `DhanavelPeriyasamy/amazon-marketplace-intelligence`.
3. Select branch `main` and main file path `Streamlit/app.py`.
4. Deploy. Upload your permitted CSV from the app sidebar.

The repository owner must complete the Streamlit account authorization and deployment confirmation. This repository update alone does not create a live hosted app.
